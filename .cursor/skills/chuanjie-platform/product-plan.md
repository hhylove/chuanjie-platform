# 产品规划摘要（对齐完整系统架构）

源文档：`创界新后台完整系统项目架构.docx`  
详情见 [architecture.md](architecture.md)。

## 定位

统一的**企业经营与创业项目管理平台**。  
内部员工在同一后台完成办公、项目、商品、运营、设计、采购、仓库、财务；外部创业者/供应商经受限协作端接入同一业务链。

## 宗旨与目标

- 减少重复填报与跨菜单查找、反复沟通  
- 统一项目 / 商品 / 店铺 / 供应商 / 组织主数据，业务可追溯  
- 角色进入即见任务、风险与关键数据  
- 打通申请→审批→执行→验收→结算→复盘  
- 为 AI 与经营分析准备结构化数据  

## 边界

| 范围 | 包含 | 边界 |
|------|------|------|
| 内部办公 | 组织、人事、考勤、培训、行政、任务、审批、日程、知识 | 服务内部员工 |
| 项目经营 | 创业者准入、立项、预算、协议、经营、关店退出 | Project ID 贯穿 |
| 商品供应链 | 商品、设计、美工、采购、供应商、仓库库存 | SPU/SKU 主数据 |
| 外部协作 | 创业者端、供应商端 | 独立视图，共用数据 |
| 历史系统 | 规则、数据、必要接口 | **不沿用旧页面与交互** |

## 建设阶段（落地顺序）

0. 工程脚手架  
1. 基础平台与 OA  
2. 项目经营闭环  
3. 商品供应链  
4. 财务与外部协作  
5. 数据与 AI  

## 关键决策（摘录）

- 前端体验与信息架构重做  
- Project ID 贯穿经营；SPU/SKU 分层  
- 外部独立视图、共用数据 + 严格字段权限  
- 模块化单体起步；审批/任务为统一公共能力  
- 店铺默认单项目归属
