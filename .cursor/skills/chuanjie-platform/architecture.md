# 完整系统项目架构摘要

源文档：`创界新后台完整系统项目架构.docx`（V1.0，2026-09）

## 1. 分层

| 层级 | 内容 |
|------|------|
| 用户体验层 | 角色工作台、统一搜索、消息、待办、移动端 |

## 2. 四端

| 端 | 使用者 | 能力 |
|----|--------|------|
| 内部管理后台 | 内部员工 | OA、项目、商品、运营、创意、供应链、财务、驾驶舱 |

| 系统管理 | 用户组织岗位角色、数据字段权限、流程表单字典编号、消息日志参数 |

## 4. 核心流程

- **项目**：准入 → 申请 → 评估 → 立项 → Project ID → 预算协议 → 执行 → 复盘 → 关店退出  
- **商品**：建议 → 选品 → 打样 → 建档 → 定价 → 设计拍摄 → 上架 → 监控 → 清仓归档  
- **采购仓**：需求 → 预算校验 → 询价 → 审批 → 订单 → 发货 → 入库 → 对账 → 付款  
- **内部 OA**：发起 → 负责人审 → 专业处理 → 财务/老板批 → 执行 → 归档  

## 5. 主数据与规则（摘录）

人员组织｜创业者｜创业项目（Project ID）｜店铺渠道｜商品（SPU/SKU）｜供应链｜财务｜协作（任务审批消息文件）

- 每项目一名创业者负责人 + 可多名成员；一名主项目运营 + 可多名协同  
- 一项目可多经营单元/渠道/店铺；店铺默认单项目；共用靠分摊规则  
- 每笔经营业务关联责任主体、来源与 Project ID  

## 6. 权限分层

身份｜功能（菜单页面按钮）｜数据范围｜字段（价/成本/利润/薪资/账号/审批意见）｜临时授权｜操作审计  

## 7. 技术分层与代码模块建议

客户端 → 接入层 → 业务应用层 → 公共服务层 → 数据层 → 集成层  

| 模块 | 职责 |
|------|------|
| platform | 用户、组织、权限、配置、字典、日志 |
| collaboration | 流程、审批、任务、消息、日程、文件 |
| oa-hr | 行政、人事、考勤、薪酬、绩效、培训 |
| project | 创业者、项目、经营单元、成员、里程碑、协议、退出 |
| product | 选品、开发、SPU/SKU、分类、成本定价、生命周期 |
| operation-creative | 店铺渠道、运营、设计、美工、素材 |
| supply-chain | 采购、供应商、仓库、库存、物流、质量 |
| finance | 预算、费用、付款、票据、流水、成本、利润、结算 |
| analytics-ai | 指标、报表、预警、知识库、AI 助手 |

首期**模块化单体**；边界守住后再拆服务。

## 8. 建设五阶段

| 阶段 | 范围 | 结果 |
|------|------|------|
| 一 | 账号组织权限、工作台、任务审批消息、人事考勤培训、行政知识 | 内部统一办公 |
| 二 | 创业者、立项、Project ID、项目空间、预算协议、经营单元店铺风险 | 项目可追踪 |
| 三 | 选品开发 SPU/SKU、定价创意、采购供应商仓库清仓 | 商品闭环 |
| 四 | 项目/商品财务、创业者端供应商端、对账结算、驾驶舱 | 内外协作与核算 |
| 五 | AI 助手、分析预警、知识库、Agent | 决策与自动化 |
