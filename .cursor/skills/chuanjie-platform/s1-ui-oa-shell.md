# S1 附属：OA 管理壳布局（对齐积云/稠云类后台）

> 状态：**已确认可开发**（用户提供积云 V3 截图「这个界面」）  
> 参考：用户截图（顶栏 + 左侧分组菜单 + 多页签 + 面包屑 + 内容区）；[稠云 OA](http://oa.cyoasoft.com/#/dashboard) 同属此类。

## 1. 目标

admin-web 登录后壳子改为 **企业 OA 作业台布局**，信息密度与结构接近参考图，而非营销落地页式顶栏。

## 2. 范围

- 顶栏：品牌「创界云枢」、工具区（主题/用户/退出）  
- 左侧：可展开分组菜单（工作台、组织管理→用户/部门/角色）  
- 多页签：打开过的路由可切换、可关闭（工作台不可关）  
- 面包屑：按当前路由展示  
- 内容区：浅底 + 白工作区  

## 3. 非目标

- 本期不做顶栏「日程/邮件」等快捷图标全集  
- 不做右侧详情抽屉、不做完整标签页缓存（keep-alive 可后补）  
- 登录页保持现有品牌动效，不改成参考图的列表页  

## 4. 验收

- [x] 布局结构与参考图同构（顶/左/签/屑/内容）  
- [x] 现有用户/部门/角色路由可在侧栏与页签中切换  
- [x] 主题切换仍可用  
- [x] 无后端改动  

## 5. 落位

- `layouts/AdminLayout.vue`（主壳）  
- 路由 `meta.title` / `meta.group`  
- 文档进度挂 progress
